Install the Local Native Host

You’ve installed the Fire vs Fire browser extension! Next, install the Native Host—the local environment where AI classification actually happens.

Why is the Native Host separate from the browser?

Web browsers run inside a restricted sandbox with limited hardware access. Real AI classification needs direct hardware & GPU acceleration to run fast enough to keep up with live web browsing.

Choose Your First-Party Classifiers

Want to build your own classifier? Click to see the BaseClassifier API BaseClassifier API ▾

Fire vs Fire isn’t limited to AI detection—that’s why ResNet 50 - Spider exists! Any Python class inheriting from BaseClassifier placed in native/classifiers/ is automatically discovered and loaded by the Native Host. Here is the complete interface: 

from abc import ABC, abstractmethod
from typing import List, Dict, Any, Optional, Set
from pathlib import Path
import sys

class BaseClassifier(ABC):
    """Abstract base class for AI detection classifiers (multi-modal)."""

    def __init__(self, model_path: Optional[Path] = None):
        self.model_path = model_path
        self.model = None
        self.device = None
        self._is_loaded = False

    @abstractmethod
    def get_supported_modalities(self) -> Set[str]:
        """Return supported modalities: {'image'}, {'text'}, {'audio'}, or {'video'}."""
        pass

    @abstractmethod
    def load_model(self) -> tuple[bool, Optional[str]]:
        """Load weights onto device. Return (success: bool, error_reason: Optional[str])."""
        pass

    @abstractmethod
    def preprocess_batch(self, inputs: List[Any], modality: str) -> tuple[Any, List[int]]:
        """Preprocess inputs for inference. Return (batch_tensor, valid_indices)."""
        pass

    @abstractmethod
    def classify_batch(self, batch_tensor: Any) -> List[float]:
        """Run model inference. Return List of scores in [0.0, 1.0], or -1.0 for error."""
        pass

    @abstractmethod
    def get_device_info(self) -> Dict[str, Any]:
        """Return dict with keys: 'device', 'name', 'backend' (e.g. CUDA, DirectML, CPU)."""
        pass

    @abstractmethod
    def get_model_name(self) -> str:
        """Return human-readable model name."""
        pass

    def get_label(self) -> str:
        """Human-readable badge label (e.g. 'AI generated', 'Spider')."""
        return "AI generated"

    def is_loaded(self) -> bool:
        """Check if model is currently loaded in memory."""
        return self._is_loaded

    def unload_model(self):
        """Unload model from memory for resource efficiency."""
        self.model = None
        self._is_loaded = False

    def process_batch(self, inputs: List[Any], modality: str) -> List[float]:
        """Convenience method combining load_model, preprocess_batch, and classify_batch."""
        if not self.is_loaded():
            success, _ = self.load_model()
            if not success:
                return [-1.0] * len(inputs)
        batch_tensor, valid_indices = self.preprocess_batch(inputs, modality)
        if not valid_indices:
            return [-1.0] * len(inputs)
        scores = self.classify_batch(batch_tensor)
        results = [-1.0] * len(inputs)
        for idx, score in zip(valid_indices, scores):
            results[idx] = score
        return results

    def _log_to_stderr(self, message: str) -> None:
        """Safe stderr logging to avoid corrupting native messaging JSON on stdout."""
        try:
            print(message, file=sys.stderr, flush=True)
        except Exception:
            pass

Setting Up Your First Classifier

How to set up your first classifier:

  • Pin Fire vs Fire to your browser bar: Click your browser's extensions icon and pin the flame icon so it is always visible.
  • Open the Options menu: Click the flame icon in your toolbar, then click Options to open your Settings dashboard.
  • Create or edit a Category: Categories group your classifiers by rules (e.g. AI Images, Spiders, or custom concepts).
  • Assign your downloaded classifiers: Check the box next to your downloaded classifiers (e.g., FvF Heimdall V2) to enable them inside that category.
  • Set your sensitivity threshold: Adjust the threshold slider (recommended: 75%). Any image or text scoring above this threshold will trigger your chosen alert style.
  • Choose your display style: Select between Hover-to-Reveal Blur, an outline Border, and an Info Badge.
  • Toolbar flame indicators: A green flame logo with a counter means active scanning is underway; a red flame means the GPU/CPU is idle standing by.
