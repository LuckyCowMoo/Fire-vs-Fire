Why is the Native Host separate from the browser?

Web browsers run inside a restricted sandbox with limited hardware access. Real AI classification needs direct hardware & GPU acceleration to run fast enough to keep up with live web browsing.

from classifiers.base_classifier import BaseClassifier

class MyCustomClassifier(BaseClassifier):
    def get_supported_modalities(self):
        return {"image"}  # or {"text"}, {"video"}, {"audio"}

    def get_model_name(self) -> str:
        return "My Custom Detector"

    def get_label(self) -> str:
        return "Custom Tag"

    def load_model(self):
        # Load your PyTorch (.pt) or ONNX weights onto GPU/CPU
        self._is_loaded = True
        return True, None

    def classify_batch(self, batch_tensor) -> list[float]:
        # Return confidence scores between 0.0 and 1.0 for each item
        return [0.95 for _ in range(len(batch_tensor))]

2. What is a Classifier vs. a Category?

Fire vs Fire separates the AI brain (Classifier) from your visual rules (Category) so you have total creative control over what gets filtered and how it looks.

🧠 The Classifier (The Brain)

Outputs a 0% – 100% Score

A Classifier is a neural network file in your Native Host—such as FvF Heimdall V2 (which detects AI images) or ResNet 50 - Spider (which detects spiders). It inspects each item on the page and returns a raw probability score.

Example: FvF Heimdall V2 scans an image → returns 0.998 (99.8% AI)
🎨 The Category (Your Rule & Style)

Decides When & How to React

A Category groups one or more Classifiers together under a single sensitivity threshold (e.g. 75%) and applies your chosen visual effect: Blur, Colored Border, and Corner Badge (on Hover, Always, or Off).

Pro Tip: Enable 2+ Classifiers in one Category to unlock linked Ensemble Weight Sliders!

4. What the Different Coloured Logos Mean

The Fire vs Fire icon in your browser toolbar changes colour in real time so you always know when your GPU is actively classifying content vs. standing by.

🔴 Red Flame Logo

Idle / Standing By

All visible images and text on the current page have been classified (or returned instantly from cache). Your GPU/CPU is completely idle and using zero compute.

🟢 Green Flame Logo + Counter

Actively Classifying Content

The Native Host is actively processing new batches of images or text as you scroll. The green badge number shows how many classification jobs are currently running, and results stream onto the page progressively!
